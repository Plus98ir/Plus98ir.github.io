This script is an All-in-One Automated Setup for building a secure and high-performance routing server. It automatically installs and configures networking, DNS management, monitoring tools, security components, and user management services.

🚀 Features

Running this script automatically performs the following tasks:

  1. System Update & Dependencies
    Installs all required packages automatically.
  2. TCP BBR Optimization
    Enables BBR and optimizes Linux networking.
  3. 3X-UI Installation
    Automatically installs the latest 3X-UI panel.
  4. DNS Server
    Configures DNS services automatically.
  5. Traffic Monitoring
    Installs vnStat, iftop, nethogs and monitoring tools.
  6. Firewall
    Applies iptables rules and server hardening.

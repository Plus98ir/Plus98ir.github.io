Your visit stats, in your own design

This page reads the numbers straight from GoatCounter. Connect it once with a read-only API key; the key stays in this browser only.

  1. Open GoatCounter → Settings → API (verify your email first if asked).
  2. Click New API key, tick only Read statistics, and save.
  3. Copy the key and paste it here.

Use a key with read-only permission. Anyone who opens this page without the key sees nothing.
